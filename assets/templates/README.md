# Art Creation Templates & Guides (`assets/templates/`)

This directory contains template guidelines and specifications for creating custom artwork for ChainGain:

## 1. Character Bust Portrait Template
- **Dimensions**: 64 x 64 px
- **Style**: 16-bit pixel art
- **Grid Setup**: Head & Helmet fit inside top 32x32 area; Neck and Shoulder Pads occupy bottom 32x32 area.
- **Save Location**: `assets/images/players/player_<name>.png`

## 2. Playbook Play Card Template
- **Dimensions**: 512 x 640 px (5:6 aspect ratio) or 114 x 90 px (Pixel Art frame)
- **Style**: Dark slate frame with vibrant neon route line diagrams (Green = Run, Cyan = Short Pass, Gold = Deep Pass/Special)
- **Save Location**: `assets/images/cards/card_<play_name>.png`

## 3. Field & Sprite Animation Sheet Template
- **Dimensions**: 128 x 128 px canvas
- **Cell Size**: 16x16 or 32x32 px grid cells
- **Save Location**: `assets/sprites/`
