# Field Animation & UI Sprites (`assets/sprites/`)

Place all transparent 16-bit pixel art animation sprites in this directory:

- `football.png` (20x16 px): Pigskin football sprite
- `tackle_boom.png` (32x32 px): Hit impact starburst
- `spotlight.png` (64x128 px): Vertical spotlight cone
- `pedestal.png` (48x16 px): Locker room floor platform
- `turf_tile.png` (32x32 px): Grass tile texture
- `arrow_left.png` (16x16 px): Left UI arrow button
- `arrow_right.png` (16x16 px): Right UI arrow button
- `btn_a.png` (24x24 px): Controller A / Select badge
- `btn_b.png` (24x24 px): Controller B / Back badge
- `btn_lt.png` (32x24 px): Controller LT Trigger badge

The game automatically applies nearest-neighbor texture filtering to all PNGs in this folder.
